# BigSteve Labs Branding

This folder contains the approved local branding package for BigSteve Labs.

## Assets

| Asset | Intended use |
|---|---|
| `brand-guide.md` | Brand rules, palette, typography, spacing, and usage guidance |
| `logo-full.svg` | Primary horizontal logo for websites, documents, and presentations |
| `logo-icon.svg` | Square BS monogram for avatars, app tiles, and social profiles |
| `logo-monochrome.svg` | Single-color mark for print, embossing, and light-background use |
| `github-banner.svg` | Wide 2048 × 576 banner for GitHub and project headers |
| `favicon.svg` | Simplified BS monogram for browser tabs and very small placements |

All artwork is original and built from SVG text and vector shapes. No external artwork or font files are required.
